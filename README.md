# Bonesaw

WotLK 3.3.5a private realm.

## Play

Run `Bonesaw.bat` from your client folder. It pulls the latest patches from [Releases](https://github.com/Raajik/wotlk-bonesaw/releases) and starts the game.

You need a 3.3.5a client with a patched `Wow.exe` already in place. The updater never downloads the exe.

## Living Gear

Equipped gear gains XP and levels. Grown stats apply on your character. `*Windblown` opens the attune window.
