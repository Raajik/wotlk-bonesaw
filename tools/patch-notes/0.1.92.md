**Bonesaw 0.1.92 - patch notes**

**Reports**
- Bug reports filed with `.bug` or `/bugreport` are now tracked automatically in GitHub.
- Feature requests can now be filed with `.feature` or `/featurerequest` and are tracked separately from bugs.
- Report status now stays linked across the in-game queue, GitHub, and Discord.

*Close Wow and run Bonesaw.exe to update.*
