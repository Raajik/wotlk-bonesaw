**Bonesaw 0.1.111 - patch notes**

Autoloot
- Autoloot now re-checks nearby lootable corpses every 5 seconds, so fresh kills get looted automatically without you moving.
- Craft refusal messages now tell you exactly which recipe is blocked and where the reagents were expected to come from.

Combat & Scaling
- Enemy pets and guardians now scale to match their master's level, instead of lagging levels behind.
- Chain Lightning damage corrected - a typo was causing absurd billion-hit scaling.
- Avenger's Shield cooldown instrumentation added to catch any relapse to the long cooldown.

Quality of Life
- Flight is now allowed in Dalaran.
- Riding skill learned on one character now pushes instantly to your online alts.
- Cold Weather Flying is now learned account-wide, like the riding skill.
- New .crit command files CRITICAL-priority reports, alongside .bug and .feature.

Close Wow and run Bonesaw.exe to update.

Needs testing
- If you had a flight point or riding skill not sync to an alt, check it synced now.
- Try casting Chain Lightning / Lightning Bolt and confirm damage looks sane.
- Paladins: confirm Avenger's Shield cooldown behaves as expected.
- If a craft is refused, check the new message names the recipe and reagent source.
