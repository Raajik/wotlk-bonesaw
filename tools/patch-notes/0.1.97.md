**Bonesaw 0.1.97 - patch notes**

**Attuned items**
- Create works and now tells you what it did. It was already making the item and putting it in your bags, but said nothing at all, so it looked like a dead button. It now reports the item by name, and says so plainly if your bags are full.
- Item names are real item links. Hover for the tooltip, shift-click to link one in chat.
- The list is two columns, so you can see twice as much at once.

**Class tab**
- Each perk line now leads with the icon of the ability it changes, and you can mouse over that icon for the ability's real tooltip. Handy for sizing up a spec you have never played.
- Perk text is grouped one entry per ability instead of one per sentence, so everything a single ability does is in one place. Rogue is done; the other classes follow.

*Close Wow and run Bonesaw.exe to update.*
