**Bonesaw 0.1.95 - patch notes**

**Attunement**
- Fixed there being no way to attune an item. The Attune All button had gone missing from the interface entirely, so the only route left was looting.
- Attune All now sits on the Items tab, next to your attuned gear. It still asks twice before it consumes anything.
- The *Attuned Armory perk works again. Casting it opens your Items list filtered to everything attuned on the account, ready to recreate.

*Close Wow and run Bonesaw.exe to update.*
