**Bonesaw 0.1.124 - patch notes**

**Auto-Attune**
- The Auto-Attune toggle actually works now: flip it on and new items attune themselves as they come in
- New Min ilvl button next to the toggle - auto-attune only takes items at or above the item level you set (0 = no minimum)
- The per-quality switches still work, and duplicates or items you already attuned are never consumed
- Everyone starts with Auto-Attune OFF after this update - turn it on if you want it

**Bot chatter**
- Bots now react when someone posts an item link in chat
- Around 75 new insults and combat taunts for the bots

**Fixes**
- Avenger's Shield should no longer get stuck on a 30 second cooldown
- /bug now opens the same report form as /report

**Please test these things**

- Post an item link in chat around bots - does anyone react?
- Cast Avenger's Shield a few times - does the icon still lock up at 30 seconds?
- Type /bug - does it open the report form?
- Craft something that needs banked reagents - does it still say missing reagent?
- Do bots still try to open trades with you?

- Does loot still tell you it will bind when you pick it up?
