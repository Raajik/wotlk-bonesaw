**Bonesaw 0.1.98 - patch notes**

**Reagent vault**
- Items in the vault are real item links now. Hover one for its tooltip, or shift-click to link it in chat.
- Escape backs out of the search box, and a second Escape closes the window. It used to swallow Escape entirely, leaving the X as the only way out.
- The search box has a clear button, and Escape no longer wipes what you typed.
- Deposit All moved to the bottom centre, matching Attune All.

**Layout**
- The tab row and the class grid are centred instead of sitting off to one side.
- Spec card titles are centred on the card.

*No realm restart for this one. Close Wow and run Bonesaw.exe to update.*
