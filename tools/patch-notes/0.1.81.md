**Bonesaw 0.1.81 - patch notes**

**No more soulbound gear**
- Equipment no longer binds. Bind-on-pickup and bind-on-equip are gone from every item in the game.
- Gear you already own has been un-bound too, so nothing is stuck to a character because of when you happened to pick it up.
- The "this will bind to you" prompt is gone with it. If you still see it once, relog and it will clear.
- Quest items and bind-on-use items are unchanged.

**Fishing**
- Auto-looting a fishing pool now gives you the whole pool instead of a single cast, and the fish the pool actually contains rather than generic open-water catches.
- Your fishing yield bonus applies to all of it.
- You get a skill-up chance per cast drained, so letting the perk fish a pool is no longer worse for levelling Fishing than casting at it yourself.

*Close Wow and run Bonesaw.exe to update.*
