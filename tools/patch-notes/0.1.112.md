**Bonesaw 0.1.112 - patch notes**

Reports
- One report button now does everything: /report (or /bugreport with no text) opens a small form where you pick Bug, Feature or Other, tick Critical and/or Recurring, and type the report.
- Paste an item link straight into the report box and it files as a clickable link; typing an item id like [item:38764] is converted to a link automatically.
- .feature and .crit still work exactly as before, so old habits keep filing reports.
- Critical and recurring reports are now tagged in Discord and on GitHub so they stand out.

Close Wow and run Bonesaw.exe to update.

Needs testing
- Try /report and file a test report with an item link pasted in - check it arrives readable in Discord.
- Check the Critical and Recurring ticks make your report show as such in Discord.
- If you had an item not leveling its stats as expected, confirm it now does.
- If a recipe says missing materials when crafting from the reagent bank, report it with the new form.
