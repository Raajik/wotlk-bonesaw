**Bonesaw 0.1.132 - patch notes**

**Changes**
- The buttons on the login and character select screens are no longer stretched and blurry. Every button was drawing a single image smeared across its whole width, so the rounded ends came out squashed the wider the button got. The ends now keep their shape at any size.
- Create New Character and Change Realm were also drawing several times wider than they were meant to, as long thin bars across the panel. They are back to a normal button size.
- Bonesaw now runs on Linux. There is a launcher that starts the game under Wine and can log you in, with your password kept in the system keyring instead of on disk. Windows is unaffected.
