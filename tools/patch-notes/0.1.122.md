**Bonesaw 0.1.122 - patch notes**

Launcher
- The auto-login was rebuilt from the ground up so your password can never land in the username field. The launcher no longer types into either box at all: your account name is pre-filled by the client itself before the login screen appears, and your saved password arrives as one clipboard paste straight into the password box.
- The launcher now waits for the game window to fully settle (several seconds) before it does anything, so slower machines have plenty of time to load. If a paste ever arrives too early for the client to catch, you simply get an empty password box and can log in by hand - nothing is ever typed into the wrong field.
- Your password is wiped from the clipboard the moment the paste is done.
