**Bonesaw 0.1.115 - patch notes**

**Reports & bug tracker**
- Fixed: reports filed through the report form or .bug were silently lost since Saturday evening. Reports reach the tracker again, and the ones lost in that window are being recovered.
- Filing a report now confirms only after the server has verified the report was actually saved. If saving fails you get an honest error instead of a false thank-you, and the text is kept in the server log for recovery.
- Fixed: shift+clicking an item while the bug report window was open threw an error and lost the link.

**PvP & objectives**
- Capture points fill roughly 25x faster everywhere: Eye of the Storm, the Eastern Plaguelands towers, Hellfire Peninsula, Halaa, Zangarmarsh, Venture Bay, Terokkar, Nagrand and the Wintergrasp banners.
- The permanent Blessing of Freedom now applies to the paladin themself automatically on login and after resurrect.

**Spells**
- Affliction DoT spread, Living Bomb and Insect Swarm now visibly creep from infected mob to mob: each hop is cast by the carrier, so the spreading animation reads correctly.

**World & quality of life**
- Flying mounts work in Dalaran.
- Every door spawn removed from Dire Maul.
- Archmage Lan'dalock weeklies award 250 of each emblem per turn-in.
- Report titles now always fit on GitHub in full.
