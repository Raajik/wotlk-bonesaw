**Bonesaw 0.1.100 - patch notes**

Class perk cards:
- Every class and spec now lists each ability by name with what it actually
  does, corrected against how the perks really work. Hover a bullet to see
  the real spell tooltip.
- Fixed wrong descriptions: Paladin Protection and Retribution, Hunter Beast
  Mastery, Shaman Enhancement, Druid Feral, Warlock Affliction and
  Demonology. Added missing ones: Avenger's Shield bonus damage and its
  Judgement proc, Bladestorm's Whirlwind/Thunder Clap autocasts, Druid
  Balance Insect Swarm spread and party Thorns, Penance's enemy ricochet.
- Spec icon and name are now centered on each card.

Armory (was the Items tab):
- Renamed to Armory.
- New "Type" filter: pick Armor or Weapons, then cycle to the exact kind
  you want - daggers, staffs, cloth, plate and so on.
- Removed the WORN/BAG labels and the "Attuned only" filter; worn or in
  bags now shows on the tooltip.
- Each item shows its attunement progress bar like the character sheet.
  Fully attuned items show a full bar.
- Bonus stats moved to the mouseover tooltip.

Reagents tab:
- Now two columns, so twice as much fits on one screen.
- Removed the item-type counter.
- Fixed the Leather category showing engineering items.
